# Focuser

> **Menos distração. Mais foco.**

O **Focuser** é um app de gerenciamento de hábitos com **IA**, criado para ajudar você a construir consistência, acompanhar sua evolução e manter o foco no que importa.

### Recursos

* Gerenciamento de hábitos
* Metas personalizadas
* Insights e análises
* Recomendações com IA
* Modo foco
* Acompanhamento de progresso

### Stack

`Tauri` · `TypeScript` · `MongoDB` · `GroqAI`
